# きづき手帳 — プロジェクトリポジトリ

「気づきを届けることで、知らなかったという後悔をなくす」を理念とする、
AI活用の気づきアプリ群のポートフォリオです。

**このファイルは、新しいチャットの冒頭に貼るためのものです。**
これ一枚で、前提が伝わるように書いてあります。

最終更新:2026年8月14日

---

## 1. どういうものか

暮らしの節目ごとに、「知らないままでは、もったいない」ことを、一日ひとつだけ届ける。
制度の情報を、急かさず、脅かさず、やわらかい言葉で手渡す。

すべてのアプリに共通する作りは、四つ。

1. **入り口の一枚** — 線画のしるしと、短い呼びかけ
2. **「今日は、ひとつだけ。」** — 一度に一本しか出さない
3. **中身** — 短い文章。制度の話も、まず気持ちから入る
4. **AIに、たずねてみませんか** — 点線の枠に、そのまま使える問いかけ文

一人ひとりで答えが違う部分は、アプリが答えを出しきらず、問いの形で手渡す。
これが4番めの役割です。

---

## 2. 文体 —「きよめ言葉」

> 説明しない。寄り添う。
> 教えない。思い出させる。
> 急かさない。ひらく。

詳しい規範は `docs/きよめ言葉_文体ガイド.md` にあります。
**新しく文章を書くときは、必ずこのガイドを先に読み込んでください。**

要点だけ:

- 漢語を減らし、やまとことばを使う(確認 → たしかめる、制度 → しくみ)
- 断定・命令にしない(〜しましょう より 〜してみませんか)
- 不安をあおらない
- ただし、**制度名・金額・年月日は正確な言葉のまま残す**

きよめ言葉の強さは、アプリごとに変えます。情緒が目的のものは全面に、
制度が中心のものは語りかけの部分だけに。

## 6. 決まっていること(迷ったらここに戻る)

- 文体は「きよめ言葉」
- 各アプリに一色だけアクセントカラー
- 全アプリに「入り口の一枚」
- AIプロンプト導線を各コンテンツに付ける
- 制度の数字は、公開前に必ず一次情報で確認する
- 大学ボランティアの活動とは切り離す
- Googleアカウントは個人用に寄せる
- きづき手帳の作業はClaudeで通す

### 渡し方の設計

実演から得た方法論です。技術ではなく、これがこのプロジェクトの核です。

- **一枚だけ渡す。** スクロールさせない
- **説明を足さない。** 聞かれたら答える
- **「感想とかいらないから」を必ず添える。** 目的が見えないと、人は身構える
- **読む場面に立ち会わない。** 評価は後日、対面で事実だけ聞く
- **その場で見せたら、同じものをあとで送っておく**
